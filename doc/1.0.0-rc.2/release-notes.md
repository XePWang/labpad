# LabPad v1.0.0-rc.2 更新说明

2026 年 11 月 21 日。相较 v1.0.0-rc.1 的更新。

## 新增

- **题集的 Debug / Release 与断点调试**。在题号旁选择构型，默认 Debug（`-g -O0`），Release 使用 `-O2`。右区「调试」可设置断点、查看变量和单步执行。在 Release 启动调试时，可切换至 Debug、继续以 Release 调试或取消。
- **导入实验文件夹**。ZIP 已解压时，从「导入 → 导入实验文件夹…」选择含 `labpad.project.json` 的目录。

## 修改

- **代码补全**。补全当前词时保留右侧表达式。行尾为空且位于新语句起点时，`if`、`for`、`while` 等模板排在对应关键字之后，选中后才展开。补全使用 CodeMirror 6 和 Lezer。
- **题集编译与自测状态**。编译产物与测试结果按构型记录。切换构型时显示其编译状态。断点调试使用独立产物，自测继续使用普通编译产物。
- **导入实验项目**。文件选择器提供「全部实验项目」「ZIP 压缩包」「JSON 项目文件」三种筛选。实验文件夹与归档走同一套项目恢复规则。

Windows x64 和 Linux x64 已实测补全、题集构型调试、实验文件夹导入及 Lab 1–4。macOS arm64 实机待验。[验证记录](verification.md)

# LabPad rc.2 助教指南补充

适用版本为 v1.0.0-rc.2 开发分支，更新于 2026 年 11 月 21 日。项目格式、批量送测和评分流程参阅 [rc.1 助教指南](../1.0.0-rc.1/ta-guide.md)。

课程可继续发放 ZIP 或项目 JSON。学生解压 ZIP 后，可直接导入含 `labpad.project.json` 的实验目录。分发前用同一份资料尝试 ZIP 和文件夹导入，核对题号、源码版本、数据文件和测试点。总资料包中有多份实验时，请引导学生选中其中要导入的实验文件夹。

使用题集复核耗时时，请选择 Release、点击「编译」，再运行测试点。题集默认的 Debug 适合功能自测和断点调试。桌面输出会注明所用构型，批量判题继续使用助教选定的 CLI 工具链和编译参数。

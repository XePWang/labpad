# LabPad rc.2 技术说明补充

适用版本为 v1.0.0-rc.2，更新于 2026 年 11 月 21 日。构建、打包、存储和 CLI 约定参阅 [rc.1 技术说明](../1.0.0-rc.1/maintainer-guide.md)。

- 补全沿用 CodeMirror 6 与 Lezer。单词候选只替换当前词，候选排序兼顾上下文和前缀匹配；语句模板由行尾与语法位置筛选。离线格式化继续使用 WASM clang-format。clangd 的 M0 试验单独归档。
- 单文件题集的构型是界面会话状态。主进程从有效编译配置派生参数，Release 清除已有优化级别，Debug 保留调试信息并清除 LTO 和符号剥离选项。常规产物按构型保留，源码版本、工具链和生效参数参与指纹。测试记录分构型，用于恢复当前题目状态和导出提示。
- 断点调试复用 CodeLLDB，绑定当前源码版本及已保存快照。两种调试启动各用自己的临时目录与 Zig 缓存，共用现有的容量和租约管理。测试点从常规编译产物取程序。
- 文件夹导入先核对根目录或唯一直接子目录的 `labpad.project.json`，再使用现有目录快照与 ZIP 恢复路径。Windows 文件选择器的扩展名使用 `zip` 和 `json`，目录选择走独立入口。

原生回归、工具链与平台覆盖见[验证记录](verification.md)。

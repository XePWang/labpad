# LabPad rc.2 学生指南补充

适用版本为 v1.0.0-rc.2 开发分支，更新于 2026 年 11 月 21 日。下载安装、源码管理和提交操作参阅 [rc.1 学生指南](../1.0.0-rc.1/student-guide.md)。

## 导入实验资料

- 拿到 ZIP 或项目 JSON 时，选择「导入 → 导入实验项目…」。文件类型可选全部实验项目、ZIP 或 JSON。
- ZIP 已解压时，选择「导入 → 导入实验文件夹…」，选中含 `labpad.project.json` 的文件夹。若外层只包了一份完整实验，选择外层也可以。导入后从 LabPad 的实验项目列表继续编辑。

## 题集的 Debug 和 Release

题号右侧的下拉框默认是 **Debug**。它使用 `-g -O0`，适合观察变量、设断点和单步执行。保存后点击「编译」，可用当前构型运行测试点。需要检查运行性能时切到 **Release**，再编译并运行测试点，Release 使用 `-O2`。

在行号旁点击设置断点，再按 F5 或从右区「调试」启动。Release 会询问是否切换到 Debug。选择「仍以 Release 调试」可以观察优化后的程序，断点可能移到邻近代码行，部分变量可能被优化掉。调试结束后，切回「测试点」即可使用已编译的当前构型。多文件项目的构建继续通过 `LPMake.txt` 配置。

## 补全

输入 `fo` 时，`for` 关键字排在语句模板前面。模板会在光标位于新语句起点、右侧到行尾只有空白时出现。用方向键选中后按 Tab 或 Enter，或直接点击，才会展开模板。编辑已有语句时，补全保留当前词右侧的表达式和标点。

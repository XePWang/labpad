编译只读取已保存文件；源码或构建参数变化后运行入口失效。测试点与规则变化可复用程序，但不会沿用旧验收结果。运行结束清理测试/调试目录，当前成功程序最多保留一份，下次编译、清理缓存或退出时释放。

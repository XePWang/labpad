# LabPad rc.3 学生指南

适用版本为 v1.0.0-rc.3，更新于 2026 年 11 月 27 日。安装、编辑和调试见 [rc.2 学生指南](../1.0.0-rc.2/student-guide.md)。

## 用自动机测试 Lab 5 计时报告

Lab 5-1 沿用原测试点。为已导入的「实验5」题集添加两道计时题时，从「导入 → 导入实验项目…」选择 [lab-5-timing.projectTests.json](../../examples/lab-5-timing.projectTests.json)，确认更新。它覆盖 Lab 5-2、5-3 的测试点与时限，保留 Lab 5-1。

如果用单题项目，选中 Lab 5-2 或 Lab 5-3，从「导入 → 导入测试点」打开对应文件，再选「覆盖现有测试点」。[Lab 5-2](../../examples/lab-5-2-timing.io.json) · [Lab 5-3](../../examples/lab-5-3-timing.io.json)

保存源码，点「编译」，再点「运行全部测试点」。计时报告第一行填写实际数据量，随后按题面顺序逐行打印算法标签与三位小数的秒数。Lab 5-3 的最后一行可写 `heapSort` 或 `heapsort`。先用小数据调试，比较算法耗时时保持相同构型。

「格式样例」提供一份可参考的报告。WA 消息给出最先出错的行和要求，「执行轨迹」列出此前通过的行。格式正确后，再自行确认每种排序都实际完成并正确输出。

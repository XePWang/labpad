## 专项复核

- **模板字段。** 顶层分支与内联标志分别通过正反例验证。每个字段独立分组，RE2JS 对整行做全串匹配。字段前后固定文本和其他字段遵循各自的匹配规则。
- **接收状态。** 自环支持重复记录，合计行可选。测试覆盖 EOF 接收、有出边但不匹配、转移后在非接收状态结束、终止状态后的多余输出。
- **格式样例。** 在成品包中编辑、保存和重载样例后仍显示 AC。CLI 单人续测同样保留批次有效性。输入、比较规则和严格期望输出的修改仍会使对应结果失效。
- **长输出。** 覆盖 16383、16384、16385 个 UTF-16 码元。桌面长行 WA 显示失败位置，摘录最多 160 个码元，实际输出预览最多 4096 个码元。CLI 的 `cases.csv` 诊断摘要最多 300 个码元。使用带引号、逗号和公式前缀的夹具写出 CSV，再读回核对列数和转义。
- **旧规则与进程结果。** 全量套件覆盖 `wcmp`、`floatTokens`、`strictText`、单点比较覆盖、非法正则、错序、少行和多行。实际进程的 TLE、OLE 和非零退出仍优先于输出比较。
- **Lab 5。** 两端均从已发放 ZIP 导入「实验5」并应用 `lab-5-timing.projectTests.json`。Lab 5-1 原测试点、Lab 5-2 和 Lab 5-3 的 `heapSort`、`heapsort` 均获 AC。两位小数的负例在第 7 行报告 WA，重载后可查看执行轨迹。计时题源码模板及《实验之前先读我》已标明使用 `%.3f`。

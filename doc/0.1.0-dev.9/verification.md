## 流程覆盖

- 文件区：刷新、Ctrl/Command 与 Shift 多选、复制粘贴、内部移动、外部二进制拖入、就地新建、F2 重命名、删除、折叠及撤销记录。
- 编辑：Tab 的 1/2/4 空格、上下文缩进、查找替换、行移动、注释、独立撤销与格式化；补全的 Tab 接受、方向键选择及 Enter 保留换行。
- 编译与测试：保存确认、取消、失败恢复、警告计数、所选范围、单点与失败重测、源码变化失效、CE/TLE/RE/OLE 和浮点/严格文本规则。
- 导入与导出：源码副本、题集与项目、覆盖/追加、点级比较、题号/版本选择、身份信息续导、ZIP 重建、数据迁移及旧模板延迟打开。
- 终端：中文与 emoji、分段 UTF-8、异步输出重绘、连续输入队列、行编辑、历史上限、EOF、中断、缩放及重复启动/停止。
- 调试：普通与条件断点、变量与堆栈、编辑后提示、重启保存/取消、中文标准输入输出、参与文件保护与退出清理。
- 资源：循环编译与关闭、保留一份 GUI 程序、旧临时目录回收；GUI 构建保持临时目录，lpmake 仅在当前配置目录 build/ 落盘并按归属清理。

## 解压资源对照

使用相同的 dev8 桌面资源与同版离线调试器，仅替换完整/本机 Zig 工具链。两包均为 Deflate 6；每组运行三次，第二轮交换顺序。Windows ZipArchive 写入真实文件，计时包含解压与落盘。以下是资源对照结果，最终成品大小见发布附件。

| 指标 | 完整工具链 | 本机工具链 |
| --- | ---: | ---: |
| 文件数 | 20,789 | 8,924 |
| 解包字节 | 974,224,085 | 916,589,599 |
| ZIP 字节 | 330,688,687 | 310,051,758 |
| 普通条件中位数 | 19.70 s | 10.35 s |
| 受限 CPU 中位数 | 55.38 s | 32.25 s |
| 受限 CPU 与 I/O 中位数 | 62.06 s | 35.15 s |

受限测试仅约束测试进程：CPU Job Object 上限约为四分之一个逻辑核，允许在两个核上调度；实际 CPU 时间/墙钟时间随记录核对。I/O 组叠加每文件约 1 ms 的高精度等待与 80 MiB/s 的写入节流。这是低性能条件模拟，具体笔记本的资源管理器解压速度还受存储、杀毒扫描及文件系统影响。

受限 CPU 三轮：完整 55.38 / 55.81 / 55.07 s，本机 32.25 / 32.26 / 32.02 s。叠加 I/O：完整 62.06 / 62.08 / 61.69 s，本机 35.21 / 35.08 / 35.15 s。

三平台本机工具链文件数分别为 Linux 6,921、Windows 7,641、macOS 3,413；原完整工具链各 19,505。Windows 与 Linux 裁剪副本均实际编译运行 C17/C++20 的 Debug/Release 样例。原开发工具链保持完整。

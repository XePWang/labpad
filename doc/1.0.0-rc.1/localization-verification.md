适用版本：1.0.0-rc.1。核验日期：2026-11-09。实现与译文维护见 [界面语言维护说明](localization.md)。

## 流程与界面检查

- 简体中文与 English 即时切换，设置取消和重启恢复；搜索/替换词、查找选项、编辑器选区、撤销记录、源码及既有 AC 结果保留。
- 已打开的快捷键窗口同步语言，未保存的键位草稿保留；终端不因切换语言重建。
- 640 px 紧凑窗口分别检查亮暗主题、搜索面板、完整英文设置及导入导出；标题栏 40 px，工具栏单行，“更多”跨分区避让并限高滚动。
- Linux 75/75、Windows 73/73 完整桌面回归；两端另行通过英文项目导入、保存、编译、送测及 ZIP 导出。
- Linux GCC/Clang、Windows GCC/Clang 各通过 16 组兼容检查；当前 CLI 归档通过 7 组检查。macOS 完成静态签名、资源与 arm64 架构核验，未进行实机运行。

## 测试夹具的时序修正

响应式工具栏会在缩放恢复时由“更多”切回直接显示“设置”。原测试先选定旧入口，随后布局改变导致定位失效；公共入口改为等待当前可见的设置按钮或菜单，随后缩放定向检查和完整回归均通过。

保存用例先收到单测试点 AC 事件，不意味着整个判题请求已结束。标签栏在判题期间保持禁用。通过受控延迟实际判题响应，验证 AC 到达后强制点击标签不会切换；待完整响应结束再确认活动源码、编辑和保存。C++ 定向重复三次及最终完整 Windows 回归均通过。首次失败没有保存完整 DOM 快照，因此不把这一已证明的时序路径写成首次失败的唯一原因。

早期日志与后续证据分开保留；结果以最终发布包的完整运行记录为准。

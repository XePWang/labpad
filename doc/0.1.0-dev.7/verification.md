## 主要流程

- 导入课程项目 → 新建或导入 C/C++ → 编辑和格式化 → 保存当前 / 全部 → 编译运行 → 查看 Diff → 导出源码 / 项目 ZIP。
- 同题多版本保留独立文本、光标和撤销历史；切题恢复最近五份，关闭、取消、放弃和最近源码恢复各有检查。
- Tab 1 / 2 / 4、Shift+Tab、Enter 上下文缩进、行注释、查找替换、多选、剪切粘贴、移动/复制行、撤销重做、保存及运行快捷键。
- 格式化单次撤销、格式化期间继续输入、自动保存、原子写入失败与重启恢复。
- 单点、选点及失败点重测；同指纹结果合并，源码/规则/编译器变化后失效，CE 不伪造测试点通过。
- 整卡语义色、亮暗主题、状态说明、焦点可见、格式化按钮显隐、窄窗口、分隔线及 75% / 200% 缩放。
- 导出题号与版本两层勾选、半选、仅检查已选项、混合语言命名、身份设置续接、迁移数据后继续导出。
- JSON 选错类型或校验失败时保留源码，显示具体原因；后台状态刷新不清除尚未关闭的错误。编译器原始诊断完整保留。
- 调试中文输入输出、拆分 UTF-8 字节、emoji、GBK/UTF-16 源码、无换行提示、持续输出、选区复制及无选区 Ctrl+C 中断。

Windows 和 Linux 各执行八轮“编译 → PTY → 停止 → 关闭版本”，检查运行目录回收及内存采样；清理缓存与迁移数据保留源码和规则。

## Windows 原生窗口补查

自动化场景对文件选择及部分确认使用固定返回值，另外通过实际系统窗口验证：

1. 取消导入后，项目与源码保持原状。
2. 从中文路径导入项目 JSON、导入中文文件名源码，副本进入当前题目并自测 AC。
3. 导出源码时核对默认文件名、C 扩展名与身份提醒；取消系统保存后可继续导出。
4. 通过系统保存窗口将源码与项目 ZIP 写入中文路径；源码 SHA-256 与导入原文件一致，ZIP 内包含两份独立版本。

独立 MinGW 实测覆盖自动检测及手动选择、GCC 类别和两种语言路径适配、C/C++17 编译、中文调试与测试点输出。该发行版放在中文安装路径时，链接器无法找到 crt2.o；改用英文安装路径后通过，学生指南已说明。

## CLI 与计分

独立 CLI 包使用桌面实际导出的混合 C/C++ ZIP，完成收件、Bubblewrap 隔离、公开/隐藏测试、最高完整版本选择、百分制 CSV 和单人重测。CSV 包含有效文件、逐题通过数、得分、采用源码及逐点情况；手工填写的含逗号、引号和换行评语在续测后保留。

核心检查另覆盖 XLS/XLSX/CSV 名单顺序及文本学号、嵌套和重复 ZIP 条目、损坏/越界/链接条目、缺交/空源码/CE/待核对、稳定同分选择、舍入闭合、覆盖同名提交后历史版本保留、索引损坏、环境故障与报告回滚。

真实 Bubblewrap 检查确认程序可以处理 UTF-8，但不能读取当前用例目录之外的隐藏评分文件。可信夹具使用 isolation: none 的检查与隔离检查分别执行。

## macOS 核验范围

macOS arm64 包完成交叉构建及 ad-hoc 签名；主程序、Electron Framework、Zig、Checker 与 arm64 PTY 模块的架构及代码页哈希一致，19,695 个资源条目通过哈希/链接检查，ZIP 中 14 个符号链接保留。

默认 Mac 键位、系统保留键、Mod 展开与旧配置迁移通过参数化测试。**尚未进行 Mac 实机启动、键盘及中文 PTY 验收，也未进行 Apple 公证。** 因此本版继续作为 dev 预发布。
